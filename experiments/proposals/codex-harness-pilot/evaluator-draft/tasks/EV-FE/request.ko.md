행사 상세 화면(`static/event.html`, `static/event.js`)에서 신청이 실패하면 입력한 내용이 모두 지워지고 신청 버튼이 비활성 상태로 남아, 새로고침하지 않으면 다시 시도할 수 없습니다. 실패해도 입력이 남고 바로 다시 시도할 수 있도록 고쳐 주세요.

요구사항:
1. 신청 요청이 실패하면(서버 오류 응답, 409 등 거절 응답, 네트워크 오류 모두) 이름·이메일·소속·메모 네 칸의 입력값을 그대로 두고, `#form-error`에 오류 메시지를 보여 주고, `#submit-button`을 다시 누를 수 있게 합니다.
2. 같은 화면에서 다시 신청하면 남아 있는 값으로 요청하고, 성공하면 지금처럼 `#confirmation`에 결과를 보여 줍니다.
3. 요청을 기다리는 동안 버튼을 여러 번 눌러도 요청은 한 번만 보내야 합니다.
4. 기존 입력 검증(이름 필수, 이메일 형식 등 요청 전 검사)과 성공 시 동작은 유지합니다. 기존 마크업의 `id`도 유지해 주세요.

확인 방법: `python tools/check_public.py`로 공개 검사를 실행할 수 있습니다(Playwright 필요). 기존 테스트 `python -m unittest discover -s tests -v`도 계속 통과해야 합니다.
